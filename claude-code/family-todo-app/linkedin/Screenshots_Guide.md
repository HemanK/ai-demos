## 📱 How to Take Screenshots on iPhone

**Method 1: Side Button + Volume Up**
- Press Side button + Volume Up simultaneously
- Screenshot saves to Photos app

**Method 2: AssistiveTouch (if you have it enabled)**
- Tap AssistiveTouch → Device → More → Screenshot

**After Taking:**
- Screenshots appear in Photos → Screenshots album
- Create new album: "Family ToDo Demo" for easy access

## 🎨 Screenshot Quality Tips

1. **Clean Up First:**
   - Close other apps (remove clutter from top bar)
   - Full battery helps (no low battery icon)
   - Good lighting (no glare on screen)

2. **Use Real Data:**
   - Don't use "Test Task 1, Test Task 2"
   - Use realistic task names like your 40-50 real tasks
   - Makes it feel more authentic

3. **Variety:**
   - Mix of categories (Shopping, Bills, Doctors)
   - Mix of priorities (High, Medium, Low)
   - Mix of statuses (Pending, In Progress, Completed)

4. **Annotations (Optional):**
   - Use iOS Markup to add arrows or highlights
   - Useful for emphasizing specific features
   - Don't overdo it—clean is better

## 📤 Sharing at Events

### Best Practices:

1. **Start Casual:**
   - Don't force the demo
   - If someone shows interest in AI/software, mention it
   - "I've been building some AI tools..."

2. **Quick or Deep:**
   - Have 30-second version (screenshots 1, 4-5 only)
   - Have 5-minute version (all 8 screenshots + discussion)
   - Read the room—are they interested or polite?

3. **Don't Share Links Yet:**
   - Just show screenshots
   - "It's in private development"
   - "Happy to share more details if you're interested"

4. **Exchange Contact:**
   - Get their LinkedIn or email
   - "I'm writing an article about it—can I send it when published?"
   - Follow up within 24-48 hours

5. **Gauge Interest:**
   - Technical interest → Deep dive into architecture
   - Business interest → Talk about use cases and roadmap
   - Hiring interest → Emphasize learning and problem-solving
   - Casual interest → Keep it short, exchange contact

## 🔒 Security Reminder

**What to Show:**
- ✅ Screenshots (safe—no code visible)
- ✅ Feature descriptions
- ✅ Technical approach (high-level)
- ✅ Learning journey

**What NOT to Share (Yet):**
- ❌ GitHub repository link
- ❌ Live deployment URL
- ❌ Source code
- ❌ Architectural diagrams with implementation details

**Reason:** Protect your IP during job search. After you land a role, you can open source it.
